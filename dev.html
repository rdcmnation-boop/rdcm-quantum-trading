🔐 Developer Security Guide

5 Core Security Features

1. JWT Token Authentication
- Tokens valid for 7 days - Auto-refresh available - Signed with SHA-256 algorithm - Header: Authorization: Bearer {token}
2. Two-Factor Authentication (2FA)
- TOTP (Time-based One-Time Password) - Authenticator app support (Google Auth, Authy) - Required for high-risk operations - Backup codes provided
3. Secure Password Policy
- Minimum 12 characters required - Salt + hashing (bcrypt) - Password reset via email verification - Change password anytime
4. API Key Management
- Generate unique API keys per client - Asymmetric encryption (RSA-2048) - Key rotation supported - Scoped permissions per key
5. Session Management
- Track all active sessions - Logout from all devices - Session timeout (30 minutes idle) - IP-based anomaly detection
